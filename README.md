
Репозиторий содержит исходный код программного комплекса, разработанного в рамках выпускной квалификационной работы. 

## Структура проекта
- /backend — серверная часть приложения (FastAPI, PyTorch, FAISS, SQLite).
- /frontend/fashion-frontend — клиентское веб-приложение (React.js, Vite).
- /data_pipeline — скрипты для предварительной обработки набора данных и построения поисковых индексов.

## Системные требования
- Python 3.10 или выше.
- Node.js (версия 16+ рекомендуется) и пакетный менеджер npm.

## Инструкция по локальному развертыванию

### 1. Подготовка баз данных и медиафайлов
В связи с ограничениями систем контроля версий на загрузку объемных бинарных данных, база изображений каталога и предвычисленные математические индексы не включены в данный репозиторий (добавлены в .gitignore). 

Для корректного запуска системы необходимо перенести предвычисленные файлы в директорию /backend:
- fashion_index.faiss (векторный индекс FAISS)
- fashion_metadata.db (реляционная база данных SQLite)
- vector_map.txt (файл маппинга идентификаторов)
- директорию /images (набор растровых изображений каталога)

В случае отсутствия данных файлов, их необходимо сгенерировать заново, запустив скрипт build_database.py из директории data_pipeline.

### 2. Запуск серверной части (Backend)
Перейдите в директорию серверной части:
cd backend

Рекомендуется создать и активировать виртуальное окружение:
python3 -m venv venv
source venv/bin/activate  # Для macOS/Linux
venv\Scripts\activate   # Для Windows

Установите необходимые зависимости:
pip install -r requirements.txt

Запустите сервер:
python3 main.py

API сервера будет доступно по адресу: http://localhost:8000
Интерактивная документация OpenAPI (Swagger): http://localhost:8000/docs

### 3. Запуск клиентской части (Frontend)
Откройте новое окно терминала и перейдите в директорию клиентского приложения:
cd frontend/fashion-frontend

Установите JS-зависимости проекта:
npm install

Запустите локальный сервер разработки:
npm run dev

Клиентское приложение автоматически откроется в браузере по адресу: http://localhost:5173
